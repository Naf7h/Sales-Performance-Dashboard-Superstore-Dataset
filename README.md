# Sales-Performance-Dashboard-Superstore-Dataset
This project explores and visualizes sales data from the Kaggle Superstore Sales dataset to identify key business insights across regions, product categories, and to track trends over time.

 🔍 Objectives
Understand sales performance by region and category

Identify top-performing products and most profitable segments

Analyze profit trends and order volume over time

🛠️ Tools Used
Excel: Data cleaning, formatting, and initial exploration

SQL: Data querying (filtering)

Tableau: Interactive dashboard creation for visual insights

📈 Key Insights
Central and West regions had the highest sales volumes

Technology and Office Supplies emerged as the most profitable categories

Some products had high sales but low profitability, signaling areas for cost optimization
